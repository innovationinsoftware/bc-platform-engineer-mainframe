# Lab z/OS 25: Explore SDSF System Panels

## Overview

Authorized users of a z/OS system can view all the details of the system configuration through SDSF (System Display and Search Facility). 

## Goals

- Explore SDSF System panels and find information about the running z/OS system.

## Part 1: Find information in SDSF 

Locate the following information in SDSF. All these items are found somewhere on one of the System panels. Note which panel contained each piece of information when you find it.

- What is the maximum number of users allowed on this system, and from which PARMLIB member did this configuration setting come? 
- Which PARMLIB data sets were used when this system was IPLed?
- What System Management Facility subsystems are active on this system?
- How many subsystems are running on this system and which one is the primary subsystem? 

This one is not on a System panel, but on a panel in group Memory. 

- Find the Virtual Storage Map and correlate some of the memory areas listed there with the diagram of a z/OS address space that was shown on a slide earlier in the presentation.
