This directory contains downloaded sample files from the z/OS system 
used for Labs in the Platform Engineer / Mainframe training course
presented in June-July 2026. 
 
The local filenames correspond to z/OS data set names in the following way:
 
Local filename: HLQ.MLQ.NAME-MEMBER = z/OS DSN: HLQ.MLQ.NAME(MEMBER)

For example:
 
Local filename: K2.PARMLIB-MSTJCL00 = z/OS DSN: K2.PARMLIB(MSTJCL00)
