# Lab z/OS 27: Learn about WLM

## Overview

The Workload Manager (WLM) is part of RMF (Resource Management Facility) and works in conjunction with several IBM products, such as DB2, CICS, MQ, and USS. 

## Goals

- Locate relevant IBM documentation and relate what you learn with information you can find on SDSF panels pertaining to WLM.

## Part 1: Find the documentation  

When you search for IBM documentation about WLM online, you will get many hits for documentation about various IBM products. This is because those products can be configured to cooperate closely with WLM, and each product has its own particular configuration details for WLM. That makes it challenging to find WLM information that is immediately useful for beginners.

For that reason, we're going to make it easier for you to find documentation that will help you get started. 

This is the start of the WLM section of IBM's z/OS documentation.
https://www.ibm.com/docs/en/zos/2.4.0?topic=pa-zos-workload-management 

This is IBM's Github repository containing information about z/OS, created and maintained by IBM employees. It includes sections about RMF and WLM among other topics. 
https://github.com/IBM/IBM-Z-zOS 

## Part 2: Use SDSF to find information about SMS

Find the information about WLM for our lab z/OS environment. Look at the various definitions and see if you understand what they mean. 

The ISPF panels for systems programmers to define WLM services and goals are not installed on the lab system. We will not be working directly with it during the bootcamp. This lab exercise is to build awareness of WLM and where to find more information about it.
