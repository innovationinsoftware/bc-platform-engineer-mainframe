# Lab z/OS 3: Explore the IBM documentation for z/OS

## Overview

The standard IBM documentation will be your go-to source of information about z/OS and its facilities and tools. You will find it useful to have a basic understanding of where the documentation is located, what kinds of information it contains, how it's organized, and IBM's style for writing technical documentation.

## Goals

- Locate the official IBM documentation for several facilities and tools relevant to the work of a platform engineer.
- Read enough introductory information about the facilities and tools to know in general what functions they perform.

## Prerequisites

1. Your local system is connected to the Internet

## Part 1: Find the landing page for z/OS documentation

Locate the landing page for z/OS documentation. We are not going to tell you the URL. You can find it via an Internet search or by asking an LLM. Optionally, add the URL to your browser favorites or bookmarks.

Once you have located the landing page, answer the following questions:

1. What is the current version of z/OS?
2. What is the oldest version of z/OS for which documentation is online? 
3. Six additional resources are listed at the bottom of the page. What is the purpose of each? (No need to go into details.)

## Part 2: Explore documentation for the current version of z/OS    

On the z/OS documentation landing page, navigate to the link for the latest version of z/OS. This page has a table of contents on the left side that can be expanded or collapsed. The main content of the page, on the right, links to various topics relevant to platform engineers under the headings "Recommended Topics" and "Getting Started". Explore these links to get a sense of what kind of information each one holds. There is no need to read the information extensively at this point.
