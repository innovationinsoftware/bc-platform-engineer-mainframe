# Lab z/OS 6: Identify JCL statements

## Overview

There are four types of JCL statements. Given a JCL file, identify the type of each JCL statement.

## Goals

- Be able to recognize each of the four JCL statement types when you see an example of one. 

## Prerequisites

1. Your local system is connected to the Internet

## Part 1: Examine JCL file provided

Either individually or as a group, review the contents of file 'jcl/crqsam.jcl' in the course repository. Identify each statement in the file as one of the following:

1. JOB statement 
2. EXEC statement 
3. DD statement 
4. Not a JCL statement
